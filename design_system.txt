5. Theme Architecture
Category colors must be implemented as theme tokens rather than scattered hardcoded values. This keeps the application scalable and ensures that changing a category theme does not require editing every component.
[data-theme="wedding"] {  --theme-primary: #FFC655;}[data-theme="baby-shower"] {  --theme-primary: #0776C6;}[data-theme="birthday"] {  --theme-primary: #F7526C;}[data-theme="house-warming"] {  --theme-primary: #314A31;}

10. Invitation Preview Experience
When a user clicks Preview, the invitation should appear quickly in a mobile-device-oriented presentation. The invitation itself should remain the visual focus.
Show immediate visual feedback
Use optimized preview assets
Keep close/back control obvious
Allow Previous / Next navigation when browsing templates
Avoid unnecessary UI around the invitation
Support keyboard navigation and reduced motion
11. Responsive Design
Every screen and component must work across large desktop, desktop, tablet, mobile and small mobile.
No fixed desktop-only layouts
Use fluid widths and max-width containers
Collapse multi-column layouts appropriately
Use full-width CTAs on mobile where useful
Maintain comfortable text sizes
Keep interactive elements touch-friendly
Never allow horizontal overflow

15. Image Guidelines
Use high-quality, relevant invitation imagery
Maintain consistent aspect ratios
Optimize all assets for web
Prefer WebP or AVIF where supported
Use responsive image sizing
Use descriptive alt text
Avoid pixelated, stretched or unnecessarily heavy images
16. Performance & Loading
The interface must feel fast, especially when users browse and preview invitations.
Lazy-load below-the-fold images
Prioritize above-the-fold content
Use responsive image srcsets
Use image compression and modern formats
Use code splitting where appropriate
Use skeletons or progressive loading for dynamic content
Avoid unnecessary JavaScript and animation libraries
Prefetch likely next template content when appropriate
Cache reusable assets

24. Design Do's & Don'ts
Do
Use SF Pro for the majority of the interface.
Use Playwrite US Trad as a selective emotional accent.
Maintain strong whitespace.
Use category colors consistently.
Keep invitation previews visually dominant.
Use clear CTAs.
Design mobile-first.
Keep motion subtle and purposeful.
Optimize images and loading.
Use reusable components and design tokens.
Don't
Do not use multiple decorative fonts.
Do not overuse Playwrite US Trad.
Do not mix unrelated palettes.
Do not use excessive gradients or heavy shadows.
Do not make cards information-heavy.
Do not hide primary actions.
Do not create fixed-width layouts.
Do not use animation everywhere.
Do not replace important HTML text with images.
Do not sacrifice performance for decorative effects.
25. Final Visual Direction
Ahvaan for You should feel like a premium digital invitation studio rather than a generic template marketplace. The product should combine modern digital product design, traditional celebration aesthetics and personal emotional storytelling.
