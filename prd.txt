1. Executive Summary
Ahvaan for You is a premium digital invitation platform for modern Indian couples, families and celebrations. The website should help visitors discover invitation designs, understand the value of digital invitations, preview templates clearly on a mobile device mockup, and move naturally toward creating an invitation.
The supplied landing page establishes the core visual language: a premium editorial layout, large expressive typography, warm celebration-oriented visuals, template cards, a four-step process, FAQ and customer testimonials. The new website must retain this visual identity rather than replacing it with a generic template-store interface.
Product principleThe website should feel like a digital invitation studio, not a catalogue. Discovery, preview and confidence should happen before the user is asked to order.

6. Home Page Requirements
6.1 Header / navigation
Desktop: logo, Home, Invitations, How It Works, Blog, About, FAQ and Create Your Invitation.
Mobile: logo plus menu trigger; open a clean navigation drawer or full-screen menu.
Navigation should indicate the current page and support smooth anchor navigation where applicable.
Header should remain usable across all viewport sizes without horizontal overflow.
6.2 Hero
Preserve the existing visual composition and editorial feel.
Use a semantic H1 such as 'Beautiful Digital Invitations for Every Special Moment'.
Primary CTA: Create Your Invitation.
Secondary CTA: Explore Invitations.
Hero imagery must be optimized and loaded with priority.
6.3 Occasion categories
Show Wedding, Reception, Sangeet, Engagement, Haldi, Mehendi, Birthday, Baby Shower, Housewarming and other supported categories.
Each category card should be clickable.
Category links should lead to indexable category pages where sufficient unique content exists.
6.4 Template showcase
Provide search, category filtering and price filtering.
Use clean template cards with image, name, event type, short descriptor, price and Preview/View action.
Do not load every full-resolution template asset on initial page load.
Use optimized thumbnails and load high-resolution assets when a user requests a preview.
6.5 Benefits
Explain practical features such as RSVP, Maps, Event Details, Music, Gallery and Easy Sharing.
Keep copy concise and benefit-oriented.
6.6 How It Works preview
Retain the four-step structure: Choose a Template, Share Your Details, We Customize It, Receive & Share.
Link to the full How It Works page.
6.7 FAQ preview
Use an accessible accordion.
Show the most useful high-intent questions and link to the full FAQ page.
6.8 Testimonials
Show customer review, name, location, profession and event type when that information is genuinely available.
Use swipeable cards on mobile rather than a dense desktop grid.
6.9 Final CTA
Reinforce the value proposition.
Primary CTA: Create Your Invitation.
Secondary CTA: Explore Templates.

16. Motion & Smooth Scrolling
Use Lenis for smooth scrolling across the experience.
Smooth anchor navigation.
Respect prefers-reduced-motion.
Do not block scrolling while animations initialize.
Use short, purposeful entrance animations.
Use subtle hover and image transitions.
Avoid excessive parallax or animations that delay content visibility.
Do not let motion interfere with keyboard navigation or screen readers.
17. Performance Requirements
17.1 Image strategy
Prefer AVIF/WebP for web images where supported.
Use responsive image sources.
Use lazy loading below the fold.
Prioritize the hero image only when it is actually part of the critical rendering path.
Do not load full-size template previews until requested.
Reserve image dimensions to prevent layout shift.
17.2 Frontend strategy
Route-level code splitting.
Lazy-load non-critical components.
Minimize JavaScript shipped to the initial page.
Avoid unnecessary third-party scripts.
Load only required font weights.
Cache static assets effectively.
